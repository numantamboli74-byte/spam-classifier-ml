# 📧 Spam Email/SMS Classifier using Machine Learning

## 📌 Project Overview

This project focuses on classifying messages as **Spam** or **Ham** using Machine Learning and Natural Language Processing techniques.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* NLP

## 🤖 Machine Learning Models

The following Naive Bayes algorithms were implemented and compared:

* Gaussian Naive Bayes
* Multinomial Naive Bayes
* Bernoulli Naive Bayes

## 🔍 Project Workflow

1. Data Loading
2. Data Cleaning & Preprocessing
3. Text Data Preparation
4. Feature Extraction
5. Train-Test Split
6. Model Training
7. Model Prediction
8. Model Evaluation
9. Comparison of Naive Bayes Models

## 📊 Evaluation

The models were evaluated using classification performance metrics to determine how effectively they distinguish between Spam and Ham messages.

## 🎯 Key Learning

This project provided hands-on experience with **Natural Language Processing, text classification, feature extraction, and Naive Bayes algorithms**.
